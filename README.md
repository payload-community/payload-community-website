# Payload CMS Community Portal

A community portal for [Payload CMS](https://payloadcms.com): posts, resources, plugins and builds, with community submissions and moderation. Built on Payload 3 (Website template), Next.js and MongoDB.

- [Getting started](docs/getting-started.md): local setup in DDEV, environment variables, tests and OAuth apps.
- [Specification](spec/README.md): brief, architecture, decisions (ADRs) and open questions.
- [AGENTS.md](AGENTS.md): rules and commands for coding agents and contributors.
